# 面经题库：Java、数据库与 AI Infra

按知识主题整理的 45 道面试题，附参考回答、深入理解、追问提醒、题目来源和参考链接。覆盖 Java 与 JVM、MySQL、Redis、网络与可观测性、Agent/RAG、CUDA 与大模型分布式训练推理。

## 本地阅读

直接双击 [index.html](index.html) 即可离线打开。页面支持分类目录、全文搜索、展开或折叠答案、深浅色切换；无需安装服务或联网。问题正文中的外部参考链接需要联网访问。

也可以直接阅读 [Markdown 原文](docs/近期面试问题分类与参考答案.md)。建议先尝试口述，再展开答案：先讲结论，再讲原理、边界和验证方法。

## 修改题库

Markdown 是唯一内容来源。修改后在项目根目录运行：

```bash
python -m pip install -r requirements.txt
python scripts/build.py
```

提交时同时更新 Markdown 和生成的 `index.html`，离线页面才会同步。
